# 与官方 ZCode 差异表

基线：官方开源版 **v3.15.1**（commit `aac4755`）。本分支在此之上只做增量，全部改动公开于 git 历史。

| 功能 | 官方版 | Better ZCode | 说明 |
| --- | --- | --- | --- |
| 重命名对话 | 仅鼠标（右键/菜单） | **F2** + 原有入口 | 快捷键可在设置改绑 |
| 归档对话 | 仅鼠标 | **F3** + 原有入口 | 带确认 |
| 删除对话 | 仅归档区可删 | **F4** + 右键菜单「删除」 | 真删除（带确认）；底层会话文件保留 |
| 置顶/未读 | 仅鼠标 | **F5 / F6** | F6 按当前状态切换 |
| 分叉并删除 | 分叉按钮（保留原对话） | 每条回复新增「从此处继续对话」 | 分叉到该消息 + 删原对话；首次有原理说明，可勾选不再提示 |
| 第三方余额面板 | 无 | 输入条 **¥** 按钮 / 上下文弹窗内嵌段 | DeepSeek/Kimi 余额+今日已用；MiMo 月度百分比；一键登录抓 Cookie |
| 供应商显示名 | — | 跟随 ZCode 供应商设置实时变化 | 非硬编码 |
| 产品身份 | ZCode | **Better ZCode**（独立 appId/图标/安装目录） | 与官方并存互不覆盖 |
| 遥测 | 内置上报 | 本分支构建**不含**遥测上报 | 构建期能力默认关闭 |

## 不改的东西（刻意保持上游）

- 业务数据目录 `~/.zcode` 与官方版共享（对话记录互通）
- 除上述外的全部宿主行为、主题、协议

## 隐私

见 [隐私说明.md](隐私说明.md)。要点：余额功能的 API key / Cookie 只存本地、只发对应厂商官方域名（白名单在 `thirdPartyBalanceIpc.ts`，公开可审计）。
