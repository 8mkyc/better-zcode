# 同步上游手册

上游 [zai-org/ZCode](https://github.com/zai-org/ZCode) 采用**快照式大版本**更新（无精细历史，一个 drop = 一个巨型 commit，约 2-4 周一次）。同步本质是**把本分支的补丁序列重放到新快照上**。

## 流程

```bash
git remote add upstream https://github.com/zai-org/ZCode.git   # 一次性
git fetch upstream
git checkout develop
git rebase upstream/main          # 或 merge，二选一保持一致即可
```

冲突解完后，按下方【验证清单】逐项过一遍，然后打 tag：

```bash
git tag v<上游版本>-fork.<本分支修订号>     # 例：v3.15.1-fork.1
git push origin develop --tags              # 触发 release.yml 自动打包发版
```

## 验证清单（每次同步后逐项过）

- [ ] F2 重命名 / F3 归档 / F4 删除当前对话
- [ ] 右键菜单：时间线/置顶/分组视图都有「删除」
- [ ] hover 任意 AI 回复 →「从此处继续」按钮可用，原对话被删、新对话保留之前上下文
- [ ] hover 上下文占用 → 第三方余额段显示（DeepSeek/Kimi 有数、MiMo 可登录）
- [ ] 设置 → 快捷键：F2-F6 可见且可改绑（含改绑到其他 F 键）
- [ ] `pnpm --filter "@zcode/desktop..." run build` 通过 → 打包安装验证图标为独立 B logo

## 原则（抄自 Open-ZCode，好用）

1. 一个功能一个主题 commit，方便独立取舍和回退
2. 能用设置开关解决的，不留代码分叉
3. 每次同步的取舍写进当次 Release notes
