# 隐私说明

适用于 Better ZCode 的余额与登录功能。原则：**数据只存本地、凭据只发对应厂商官方域名**。

## 我们读取什么

| 数据 | 来源 | 用途 |
| --- | --- | --- |
| 供应商配置（名称 / Base URL / API key） | `~/.zcode/v2/provider_config.json`（你自己配置的自定义模型） | 自动发现可查余额的供应商 |
| 今日 tokens 用量 | `~/.zcode/cli/db/db.sqlite`（ZCode 本地统计库，**只读打开**） | 面板"今日 tokens"行 |

## 我们发送什么

| 请求 | 目标域名 | 携带凭据 |
| --- | --- | --- |
| DeepSeek 余额 | `api.deepseek.com` | 你的 DeepSeek API key（Bearer） |
| Kimi 余额 | `api.moonshot.cn` | 你的 Kimi API key（Bearer） |
| MiMo Tokens Plan 用量 | `platform.xiaomimimo.com` | 你的小米平台登录 Cookie（你主动粘贴或登录窗抓取） |

域名白名单硬编码在 `thirdPartyBalanceIpc.ts` 并经代码评审公开可审计；**任何其他域名的请求都会被拒绝**。

## 我们存储什么

- 余额缓存与日快照：浏览器 localStorage + `~/.balance-bar/`（若有），**只存本机**
- MiMo 登录 Cookie：localStorage `zcode:mimoCookie`，只发往 `xiaomimimo.com`
- 不上传、不分享、无遥测（本分支构建不含官方遥测上报能力）

## 删除

- 清除余额缓存/日快照：删除 `~/.balance-bar/` 与浏览器 localStorage 对应键
- Cookie：设置对话框清空即可

## 边界

- MiMo 用量接口为社区逆向的控制台接口，小米可能随时变更；失效时面板会提示重新登录
- 代码即事实：全部数据流可在本仓库公开源码中审计
